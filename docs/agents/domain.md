# Domain Docs

**Layout:** Single-context

| Datei/Ordner | Zweck |
|---|---|
| `CONTEXT.md` (Repo-Root) | Domänensprache, Kernkonzepte, Glossar |
| `docs/adr/` | Architekturentscheidungen (ADRs) |

## Regeln für Skills

- Vor Architektur- oder Debugging-Aufgaben zuerst `CONTEXT.md` lesen.
- ADRs in `docs/adr/` vor Entscheidungen konsultieren, die bestehende Designentscheide berühren.
- Neue ADRs unter `docs/adr/NNNN-kurztitel.md` ablegen.
