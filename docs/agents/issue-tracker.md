# Issue Tracker

**Tracker:** GitHub Issues  
**Repo:** `github.com/pipe3/u-checker`  
**CLI:** `gh` (GitHub CLI)

## Verhalten

- Issues anlegen: `gh issue create`
- Issues lesen: `gh issue list` / `gh issue view`
- Labels setzen: `gh issue edit --add-label`
- Externe PRs sind **keine** Triage-Quelle — nur Issues werden triagiert.
